# Rang De Festival Gathering

Build Phase 1 of the Rang De Fest landing page. Use the two attached posters as visual references, not as full-page background images. Create a premium, polished, responsive hero section and navigation using React, TypeScript, and the existing project styling setup. Design direction: sophisticated Indian festive editorial, warm ivory/cream background, vivid magenta, vermilion orange, turmeric yellow, teal, emerald green, subtle paper texture, painterly color strokes, delicate botanical motifs and authentic festival-night photography. Use large expressive display typography for “Rang De Fest”, balanced with clean, readable sans-serif typography. Header: HYD Pop-Up and RETAJ Academy organizer identities, a compact navigation menu and a prominent Register Now button. Hero: a small “HYD POP-UP PRESENTS” eyebrow, headline “Rang De Fest”, tagline “Bright. Enjoy. Festive Colours. Joy.”, a short inviting description, date 31 October 2026, time 6 PM–12 AM, and venue RETAJ Academy, Qasimabad, Hyderabad. Include a primary “Register Now” CTA and a secondary “Explore the Festival” anchor button. Show a subtle FREE ENTRY label. Use the supplied poster information accurately. Create an intentional desktop composition with a strong visual focal point and an excellent mobile layout. Use real image assets where available; if generating or sourcing imagery, ensure it is appropriate for an Indian festive marketplace. Do not use emoji as a substitute for visual design, do not put the entire poster into the hero, do not invent logos, and do not invent the registration URL. Keep the registration destination in one centralized configuration constant, initially empty, so I can supply the actual URL later. When empty, the CTA should clearly indicate that registration setup is pending rather than navigating to a fake URL. Implement this phase and preserve a clean, reusable component structure.
